要自定义 MyBatis-Plus Generator 的模板，你需要为不同的代码文件（如实体类、Mapper 接口、Service 接口、ServiceImpl 实现类、Controller 等）创建对应的 FreeMarker 模板文件。这些模板文件将决定生成的代码结构和内容。

下面我将为你提供所有常见的模板示例，并展示如何将它们集成到 MyBatis-Plus Generator 中。

### 1. 创建模板目录

首先，在项目的 `src/main/resources` 目录下创建一个 `templates` 文件夹，用于存放所有的 FreeMarker 模板文件。

```
src/main/resources/templates/
    ├── entity.java.ftl
    ├── mapper.java.ftl
    ├── service.java.ftl
    ├── serviceImpl.java.ftl
    ├── controller.java.ftl
    └── mapper.xml.ftl
```

### 2. 自定义模板示例

#### 2.1 `entity.java.ftl` - 实体类模板

```ftl
package ${package.Entity};

import com.baomidou.mybatisplus.annotation.TableName;
import java.io.Serializable;

/**
 * <p>
 * ${table.comment!}
 * </p>
 *
 * @author ${author}
 * @since ${date}
 */
@TableName("${table.name}")
public class ${entity} implements Serializable {

    private static final long serialVersionUID = 1L;

    <#list table.fields as field>
    /**
     * ${field.comment!}
     */
    private ${field.propertyType} ${field.propertyName};
    </#list>

    // Getter and Setter methods
    <#list table.fields as field>
    public ${field.propertyType} get${field.capitalName}() {
        return ${field.propertyName};
    }

    public void set${field.capitalName}(${field.propertyType} ${field.propertyName}) {
        this.${field.propertyName} = ${field.propertyName};
    }
    </#list>
}
```

#### 2.2 `mapper.java.ftl` - Mapper 接口模板

```ftl
package ${package.Mapper};

import ${package.Entity}.${entity};
import com.baomidou.mybatisplus.core.mapper.BaseMapper;

/**
 * <p>
 * ${table.comment!} Mapper 接口
 * </p>
 *
 * @author ${author}
 * @since ${date}
 */
public interface ${table.mapperName} extends BaseMapper<${entity}> {

}
```

```ftl

/**

 * ${table.comment!} 服务类
 * </p>
 *
 * @author ${author}
 * @since ${date}
 */

```

#### 2.4 `serviceImpl.java.ftl` - ServiceImpl 实现类模板

```ftl
package ${package.ServiceImpl};

import ${package.Entity}.${entity};
import ${package.Mapper}.${table.mapperName};
import ${package.Service}.${table.serviceName};
import com.baomidou.mybatisplus.extension.service.impl.ServiceImpl;

/**
 * <p>
 * ${table.comment!} 服务实现类
 * </p>
 *
 * @author ${author}
 * @since ${date}
 */
@Service
public class ${table.serviceImplName} extends ServiceImpl<${table.mapperName}, ${entity}> implements ${table.serviceName} {

}
```

#### 2.5 `controller.java.ftl` - Controller 控制器模板

```ftl
package ${package.Controller};

import ${package.Entity}.${entity};
import ${package.Service}.${table.serviceName};
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.web.bind.annotation.*;

import java.util.List;

/**
 * <p>
 * ${table.comment!} 前端控制器
 * </p>
 *
 * @author ${author}
 * @since ${date}
 */
@RestController
@RequestMapping("/${table.entityPath}")
public class ${table.controllerName} {

    @Autowired
    private ${table.serviceName} ${table.serviceBeanName};

    /**
     * 查询所有数据
     */
    @GetMapping("/list")
    public List<${entity}> list() {
        return ${table.serviceBeanName}.list();
    }

    /**
     * 根据ID查询
     */
    @GetMapping("/{id}")
    public ${entity} getById(@PathVariable("id") Long id) {
        return ${table.serviceBeanName}.getById(id);
    }

    /**
     * 新增
     */
    @PostMapping("/save")
    public boolean save(@RequestBody ${entity} ${entity.toLowerCase()}) {
        return ${table.serviceBeanName}.save(${entity.toLowerCase()});
    }

    /**
     * 更新
     */
    @PutMapping("/update")
    public boolean update(@RequestBody ${entity} ${entity.toLowerCase()}) {
        return ${table.serviceBeanName}.updateById(${entity.toLowerCase()});
    }

    /**
     * 删除
     */
    @DeleteMapping("/{id}")
    public boolean delete(@PathVariable("id") Long id) {
        return ${table.serviceBeanName}.removeById(id);
    }
}
```

#### 2.6 `mapper.xml.ftl` - Mapper XML 文件模板

```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE mapper PUBLIC "-//mybatis.org//DTD Mapper 3.0//EN" "http://mybatis.org/dtd/mybatis-3-mapper.dtd">
<mapper namespace="${package.Mapper}.${table.mapperName}">

    <!-- 通用查询映射结果 -->
    <resultMap id="BaseResultMap" type="${package.Entity}.${entity}">
        <#list table.fields as field>
        <result column="${field.name}" property="${field.propertyName}" />
        </#list>
    </resultMap>

    <!-- 通用查询结果列 -->
    <sql id="Base_Column_List">
        <#list table.fields as field>
        ${field.name}<#if field_has_next>,</#if>
        </#list>
    </sql>

</mapper>
```

### 3. 配置模板路径

在 `FastAutoGenerator` 中配置模板路径，指定使用我们自定义的 FreeMarker 模板。

```java
import com.baomidou.mybatisplus.generator.FastAutoGenerator;
import com.baomidou.mybatisplus.generator.config.OutputFile;
import com.baomidou.mybatisplus.generator.engine.FreemarkerTemplateEngine;

import java.util.Collections;

public class CodeGenerator {

    public static void main(String[] args) {
        FastAutoGenerator.create("jdbc:mysql://localhost:3306/your_database?useUnicode=true&characterEncoding=utf8&serverTimezone=UTC", "username", "password")
                .globalConfig(builder -> {
                    builder.author("YourName") // 设置作者
                            .outputDir(System.getProperty("user.dir") + "/src/main/java") // 指定输出目录
                            .fileOverride() // 覆盖已有文件
                            .disableOpenDir(); // 禁止打开输出目录
                })
                .packageConfig(builder -> {
                    builder.parent("com.example") // 设置父包名
                            .moduleName("demo") // 设置模块名
                            .pathInfo(Collections.singletonMap(OutputFile.mapperXml, System.getProperty("user.dir") + "/src/main/resources/mapper")); // 设置mapper.xml生成路径
                })
                .strategyConfig(builder -> {
                    builder.addInclude("your_table_name") // 设置需要生成的表名
                            .addTablePrefix("t_", "c_"); // 设置过滤表前缀
                })
                .templateConfig(builder -> {
                    builder.entity("/templates/entity.java") // 指定实体类模板
                            .mapper("/templates/mapper.java") // 指定Mapper接口模板
                            .service("/templates/service.java") // 指定Service接口模板
                            .serviceImpl("/templates/serviceImpl.java") // 指定ServiceImpl实现类模板
                            .controller("/templates/controller.java") // 指定Controller模板
                            .xml("/templates/mapper.xml"); // 指定Mapper XML模板
                })
                .templateEngine(new FreemarkerTemplateEngine()) // 使用FreeMarker引擎模板
                .execute();
    }
}
```

### 4. 运行代码生成器

运行 `CodeGenerator` 类中的 `main` 方法，MyBatis-Plus Generator 将会根据你配置的数据库表和 FreeMarker 模板生成相应的代码。
