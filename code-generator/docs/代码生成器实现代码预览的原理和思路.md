实现 **MyBatis-Plus Generator 代码预览** 功能，核心目标是：**在不实际写入磁盘的情况下，将即将生成的代码内容返回给前端进行展示**。这在 Web 化的代码生成平台中非常常见，尤其适用于银行/保险等对变更敏感的场景（先预览，确认无误后再生成）。

下面从 **后端实现原理** 和 **前端预览方案（Vue3 + TypeScript）** 两方面详细说明：

---

## 一、后端实现原理（Spring Boot + MyBatis-Plus Generator）

MyBatis-Plus Generator 默认使用 `FileOutConfig` 将模板渲染结果写入文件。要实现 **预览**，关键在于 **拦截模板渲染结果，不写文件，而是收集为字符串**。

### ✅ 核心思路：自定义 `FileOutConfig` + 内存输出

MyBatis-Plus Generator 允许通过 `InjectionConfig` 注入自定义文件生成逻辑。我们可以：

1. **不设置 `outputDir`**（或设为临时目录）；
2. **重写每个模板的输出逻辑**，将内容写入 `StringWriter` 而非文件；
3. **收集所有生成的文件内容**（路径 + 内容）；
4. **以 JSON 形式返回给前端**。

### 🔧 实现步骤

#### 1. 创建一个 `PreviewGenerator` 工具类

```java
public class PreviewGenerator {

    public static List<GeneratedFile> previewCode(DataSourceConfig dsc, 
                                                  GlobalConfig gc,
                                                  PackageConfig pc,
                                                  StrategyConfig sc) {
        List<GeneratedFile> files = new ArrayList<>();

        // 自定义 InjectionConfig：拦截所有模板输出
        InjectionConfig injectionConfig = new InjectionConfig.Builder()
            .beforeOutputFile((filePath, content) -> {
                // filePath 是相对路径，如 /com/example/entity/User.java
                files.add(new GeneratedFile(filePath, content));
            })
            .build();

        // 禁用实际文件输出（关键！）
        gc = new GlobalConfig.Builder()
            .outputDir(System.getProperty("java.io.tmpdir")) // 任意目录，但不会真用
            .disableOpenDir() // 不打开目录
            .author(gc.getAuthor())
            .build();

        // 配置模板引擎（默认是 Velocity，也可用 Freemarker）
        TemplateConfig templateConfig = new TemplateConfig.Builder()
            .disable(TemplateType.XML) // 按需启用/禁用
            .build();

        // 执行生成（实际会调用 beforeOutputFile 回调）
        new AutoGenerator(dsc)
            .global(gc)
            .packageInfo(pc)
            .strategy(sc)
            .injection(injectionConfig)
            .template(templateConfig)
            .execute();

        return files;
    }

    // DTO
    public static class GeneratedFile {
        private String path;
        private String content;
        // constructor, getters...
    }
}
```

> 💡 关键点：`beforeOutputFile` 回调在 **写入文件前** 被调用，此时 `content` 已是渲染好的代码字符串。

#### 2. 提供 REST API

```java
@PostMapping("/preview")
public ResponseEntity<List<PreviewGenerator.GeneratedFile>> preview(@RequestBody CodeGenRequest req) {
    // 从 req 构建 dsc, gc, pc, sc...
    List<GeneratedFile> files = PreviewGenerator.previewCode(dsc, gc, pc, sc);
    return ResponseEntity.ok(files);
}
```

## 二、前端实现（Vue3 + TypeScript）

前端需要一个 **代码编辑器组件** 来高亮显示不同语言的代码（Java、XML、YAML 等），并支持多文件切换。

### ✅ 推荐工具：**Monaco Editor**（VS Code 同款）

- 支持语法高亮、行号、只读模式；
- 完美支持 Java、XML、SQL、YAML、JSON 等；
- Vue3 官方封装：`@monaco-editor/vue`

### 🔧 实现步骤

#### 1. 安装依赖

```bash
npm install @monaco-editor/vue
# 或使用 unplugin-monaco-editor（按需加载，体积更小）
```

#### 2. 创建预览组件 `CodePreview.vue`

```vue
<template>
  <div class="code-preview">
    <!-- 文件列表 -->
    <div class="file-tabs">
      <button
        v-for="file in files"
        :key="file.path"
        @click="selectFile(file)"
        :class="{ active: selectedFile?.path === file.path }"
      >
        {{ getFileName(file.path) }}
      </button>
    </div>

    <!-- 代码编辑器 -->
    <div v-if="selectedFile" class="editor-container">
      <MonacoEditor
        :value="selectedFile.content"
        :language="getLanguage(selectedFile.path)"
        :options="{ readOnly: true, minimap: { enabled: false } }"
        style="height: 600px; border: 1px solid #ddd"
      />
    </div>
  </div>
</template>

<script setup lang="ts">
import { ref, PropType } from 'vue'
import MonacoEditor from '@monaco-editor/vue'

interface GeneratedFile {
  path: string
  content: string
}

const props = defineProps({
  files: {
    type: Array as PropType<GeneratedFile[]>,
    required: true
  }
})

const selectedFile = ref<GeneratedFile | null>(null)

const selectFile = (file: GeneratedFile) => {
  selectedFile.value = file
}

// 默认选中第一个文件
if (props.files.length > 0) {
  selectedFile.value = props.files[0]
}

const getFileName = (path: string) => path.split('/').pop()

const getLanguage = (path: string): string => {
  if (path.endsWith('.java')) return 'java'
  if (path.endsWith('.xml')) return 'xml'
  if (path.endsWith('.yml') || path.endsWith('.yaml')) return 'yaml'
  if (path.endsWith('.sql')) return 'sql'
  return 'plaintext'
}
</script>

<style scoped>
.file-tabs {
  display: flex;
  gap: 8px;
  margin-bottom: 10px;
  flex-wrap: wrap;
}
.file-tabs button {
  padding: 4px 12px;
  border: 1px solid #ccc;
  background: #f5f5f5;
  cursor: pointer;
}
.file-tabs button.active {
  background: #e6f7ff;
  border-color: #1890ff;
}
.editor-container {
  border-radius: 4px;
  overflow: hidden;
}
</style>
```

#### 3. 在页面中调用

```ts

codeFiles.value = data // 传递给 CodePreview 组件
```

## 三、注意事项（结合你的业务背景）

1. **安全性**：
    - 预览接口仍需连接目标数据库，确保数据源权限隔离；
    - 禁止预览敏感表（如用户隐私表），可在后端加白名单校验。

2. **性能**：
    - 预览只生成少量表（如 ≤10 个），避免一次性生成上百个文件导致内存溢出；
    - 可限制单次预览的表数量。

3. **PostgreSQL 支持**：
    - MyBatis-Plus Generator 能正确读取 PostgreSQL 的字段注释（来自 `pg_description`），预览时也会包含 `@ApiModelProperty` 或 `@TableField(comment = "...")`。

4. **模板定制**：
    - 如果你自定义了模板（如增加 Swagger 注解、审计字段），预览会如实反映。
