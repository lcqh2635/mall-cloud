MySQL中常用的运算符包括：

1. 算术运算符：
   - 加法：+
   - 减法：-
   - 乘法：*
   - 除法：/
   - 取模（取余数）：% 

2. 比较运算符：
   - 等于：=
   - 不等于：!= 或 <>
   - 大于：>
   - 小于：< 
   - 大于等于：>=
   - 小于等于：<=

3. 逻辑运算符：
   - 与：AND 或 &&
   - 或：OR 或 ||
   - 非：NOT 或 !

4. 字符串运算符：
   - 字符串连接：CONCAT() 或 ||
   - 字符串匹配：LIKE
   - 正则表达式匹配：REGEXP 或 RLIKE

5. 空值运算符：
   - 空值判断：IS NULL
   - 非空值判断：IS NOT NULL

这些是MySQL中常用的运算符，你可以根据具体的需求在SQL语句中使用它们来进行各种操作和条件判断。
