**n8n** 是一个开源的、基于节点的自动化工作流工具（Workflow Automation Tool），用于连接不同的应用程序、服务和 API，实现任务的自动执行。它的名字来源于“node”（节点）和“8”（代表“for”，发音类似“eight”），意思是“for nodes”——即通过节点来构建流程。

---

### ✅ n8n 的核心作用

**n8n 的主要作用是：让非程序员也能（或开发者更高效地）自动化跨平台、跨系统的任务，无需编写大量代码。**

你可以把它理解为：
> “**像乐高积木一样拼接各种应用，自动完成重复性工作**”

---

### 🌟 n8n 的主要特点与优势

| 特点 | 说明 |
|------|------|
| **可视化拖拽界面** | 通过图形化界面拖拽“节点”（Node）来构建流程，无需写代码（但支持 JavaScript 自定义逻辑） |
| **开源免费** | 完全开源（MIT 许可证），可自托管，无功能限制，适合企业私有部署 |
| **支持海量集成** | 内置 300+ 个官方节点（如 Slack、Telegram、Google Sheets、Airtable、MySQL、Webhook、HTTP、Zapier、Notion、Salesforce 等） |
| **灵活的数据处理** | 每个节点可以过滤、转换、映射数据，支持 JavaScript 表达式和函数 |
| **支持触发器 + 动作** | 可设置“触发节点”（如收到邮件、表单提交）自动启动后续一系列操作 |
| **自托管 & 隐私安全** | 可部署在自己的服务器/云上，数据不经过第三方，适合对隐私要求高的场景 |
| **社区活跃 + 插件扩展** | 支持自定义节点开发，社区贡献丰富，生态持续增长 |

### 💡 典型应用场景

| 场景 | 实现方式 |
|------|----------|
| **自动收集表单数据到 Google Sheets** | Webhook → Google Sheets 节点 |
| **新客户注册后发欢迎邮件 + 创建 CRM 记录** | Form 提交 → SendGrid 邮件 + Airtable 创建记录 |
| **每天早上 9 点发送 Slack 汇报日报** | Cron 触发 → 查询数据库 → 格式化内容 → 发送到 Slack |
| **监控网站状态，异常时通知 Telegram** | HTTP 请求 → 判断状态码 → 如果失败 → 发送 Telegram 消息 |
| **从 Shopify 订单同步到 Notion 数据库** | Shopify Webhook → 数据映射 → Notion 更新页面 |
| **自动备份数据库到云端** | MySQL 节点 → 导出数据 → 上传到 AWS S3 或 Google Drive |

### 🔧 与 Zapier / Make（Integromat）的区别

| 对比项 | n8n | Zapier / Make |
|--------|-----|----------------|
| 成本 | 免费开源，自托管 | 按使用量收费（免费版有限制） |
| 隐私 | 数据完全在你控制下 | 数据经由其云平台中转 |
| 扩展性 | 支持自定义节点、完整 JS 控制 | 限制较多，定制能力弱 |
| 部署 | 需要自己部署（Docker/云服务器） | 一键使用，无需运维 |
| 适合人群 | 技术用户、企业、注重隐私者 | 普通用户、小企业、快速上手 |

> ✅ 如果你追求**自由、隐私、可控、低成本**，选 n8n  
> ✅ 如果你只想**快速搭个简单流程**，不想折腾技术，选 Zapier

### 📦 如何开始？

1. **在线试用**：[https://n8n.io](https://n8n.io) → 免费云版本
2. **本地部署**：用 Docker 一行命令即可运行：
   ```bash
   docker volume create n8n_data

   docker run -it --rm \
     --name n8n \
     -p 5678:5678 \
     -v n8n_data:/home/node/.n8n \
     n8nio/n8n
   ```
3. 访问 `http://localhost:5678` 开始搭建你的第一个工作流！
